# Bad Language Compiler

This repo is the compiler for the BadLanguage. This project idea and motivation was completely from [Zen Programming Language Compiler](https://github.com/zenlang-rs/compiler)
Bad Language consists of Hindi Profanities as functions and keywords even for assignment. Means everything you can imagine just write it with some Gaali (Profanity). The complete guide will be available soon. 

### Example and working

for a basic example and workflow below is the snippet for the print and assignment of the variable.

```
Haan Meri Jaan
bhadwa x matlb 10
bolna x
Bhag Bsdk
```

| Syntax | Description |
|---|---|
| Haan Meri Jaan | Starting point |
| bhadwa x matlab 10 | variable x = 10 |
| bolna x | print x |
| Bhag Bsdk | return and end of Program |
